# assets/widevine

Каталог бандлится в приложение целиком (во Flutter нет ни глобов, ни
опциональных ассетов), поэтому он должен существовать. Содержимое для
публичной сборки не нужно: DRM-треки играют только в официальной
macOS-сборке, в остальных пропускаются как «unavailable».

Файлы `*.wvd` в git не попадают никогда (`.gitignore`), а Windows/Linux-джобы
релиза падают на любом из них (`tool/check_no_wvd.sh`).
