# roadmap

in order. one thing ships before the next starts.

**now: ship it.** get the release pipeline green and put out signed builds.

**next: same app on every os**
- media keys and now-playing on windows (smtc) and linux (mpris)
- a sign-in on windows that doesn't lag
- `waveform://` links on windows and linux
- windows ev code signing so smartscreen stops asking

**then: one feature per release**
- shuffle across all your likes
- light theme that follows the system
- reduced motion + a full voiceover pass
- stats: hour-of-week heatmap from `played_at`
- lyrics on the track page

**someday**
- drag tracks between playlists
- always-on-top mini player, 300×120
- official oauth 2.1 + pkce if soundcloud ever reopens registration
